Rota 3 — Consulta de FAQ (Ajuda)

As mensagens classificadas como dúvidas ou solicitações de ajuda são analisadas pela IA, que consulta uma base de conhecimento com perguntas e soluções frequentes. Quando uma solução é encontrada, uma resposta automática é enviada ao usuário e o fluxo é encerrado. Caso não exista uma solução cadastrada, a mensagem é encaminhada para a equipe humana de suporte de TI.

Descrição

A Rota 3 é destinada às mensagens que apresentam dúvidas ou solicitações de ajuda que podem, inicialmente, ser solucionadas por meio de uma base de conhecimento.

Objetivo da rota

O objetivo é utilizar a inteligência artificial para verificar se a dúvida apresentada pelo usuário possui uma solução previamente cadastrada na base de conhecimento (FAQ). Dessa forma, perguntas que já possuem uma resposta conhecida podem ser resolvidas automaticamente.

Como funciona

Quando uma mensagem é direcionada para a Rota 3, a IA consulta uma base de conhecimento em uma planilha de FAQ. O modelo analisa a dúvida recebida e verifica se existe uma solução correspondente cadastrada.

Verificação no FAQ

O sistema possui dois possíveis caminhos:

  • Se SIM: quando existe uma solução correspondente na base de conhecimento, o sistema gera uma resposta automática, envia a orientação ao usuário e encerra o fluxo.
  • Se NÃO: quando não existe uma solução adequada no FAQ, a mensagem é encaminhada para a equipe humana de suporte de TI, que poderá analisar a solicitação e realizar o atendimento necessário.

Integração com a base de conhecimento

A IA utiliza uma base de conhecimento organizada em uma planilha de perguntas e respostas frequentes (FAQ). Essa integração permite consultar soluções já cadastradas antes de encaminhar a solicitação para um profissional.

Quando essa rota é utilizada?

  • Dúvidas sobre procedimentos de TI;
  • Perguntas frequentes;
  • Problemas que podem possuir uma solução já documentada;
  • Orientações sobre utilização de sistemas ou equipamentos;
  • Solicitações que podem ser respondidas por instruções previamente cadastradas.

Resultado final

Quando a solução é encontrada no FAQ, o atendimento é automatizado e encerrado após o envio da resposta. Caso não seja encontrada uma solução compatível, a solicitação é encaminhada para a equipe humana de suporte de TI.

Fluxo resumido

E-mail recebido → Classificação como Ajuda/Dúvida → Consulta à base de FAQ → Solução encontrada?

SIM → Gerar resposta automática → Enviar ao usuário → Encerrar fluxo

NÃO → Encaminhar para equipe de suporte de TI → Atendimento humano
